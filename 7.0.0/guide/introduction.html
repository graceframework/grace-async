1 Introduction

This project contains APIs and libraries that integrate Grace with various asynchronous libraries and frameworks such as GPars and RxJava, RxJava2, RxJava3.

The Async framework aim to simplify concurrent programming within the framework and include the concept of Promises and a unified event model, and the Events framework provides a new Events API that replaces the previous implementation that was based on Reactor 2.x (which is no longer maintained and deprecated).
